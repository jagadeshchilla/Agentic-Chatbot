# AI News Summarizer

An intelligent AI-powered application built with LangGraph that provides news summarization and chatbot capabilities using Groq LLM.

## Features

- 🤖 **Basic Chatbot**: Interactive chatbot powered by Groq LLM
- 🌐 **Chatbot With Web**: Enhanced chatbot with web search capabilities using Tavily
- 📰 **AI News Summarizer**: Get daily, weekly, monthly, or yearly AI news summaries

## How to Use

1. Select your preferred LLM provider (Groq)
2. Choose a model from the available options
3. Enter your Groq API Key (get it from https://console.groq.com/)
4. Select a use case
5. Start chatting or request news summaries!

## Requirements

- Groq API Key (free at https://console.groq.com/)
- Tavily API Key (for web search features - get it from https://tavily.com/)

## Technologies Used

- **LangGraph**: For building stateful AI agentic workflows
- **LangChain**: LLM framework
- **Streamlit**: Web interface
- **Groq**: High-performance LLM inference
- **Tavily**: Web search API
